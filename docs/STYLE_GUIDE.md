# 비주얼 스타일 가이드 (게임 캔버스)

엔진 판정·규칙·조작은 원본 그대로. 이 문서는 그리기만 다룬다. 색 값의 원본은 `assets/tanks/_src/palette.mjs` → `assets/palette.json`.

## 1. 방향
- 플랫 벡터 + 부드러운 그라데이션. 외곽선 `#0B0E16`(어두운 남색 검정)으로 실루엣 확보.
- 광원: 왼쪽 위. 하이라이트는 위·왼쪽, 그림자는 아래·오른쪽.
- 노이즈·텍스처는 지형에만 약하게. 탱크는 깨끗한 면.
- 원본 의미는 유지: 벽 색, 플레이어 고정 색, 하늘 7종, 핵폭발의 크기감.

## 2. 해상도·스케일
| 항목 | 규칙 |
|---|---|
| 월드 | 엔진 논리 해상도(W×H game px) 고정. 판정은 전부 이 좌표 |
| 표시 종횡비 | `DISPLAY_ASPECT`(renderer.js, 기본 4/3). 원본 360x480 모드는 비정방 픽셀(h/w≈0.55)로 4:3 화면에 표시됐다. 월드 좌표는 그대로, 화면 변환만 x 배율 kx, y 배율 ky(360x480 에서 kx/ky≈1.778) |
| 화면 배율 | 비정수. 캔버스 = 가용 영역 안 최대(종횡비 고정). 넓은 화면은 좌 조작·우 플레이어 패널, 세로 모바일은 캔버스 폭 = 뷰포트 폭. 캔버스 밖은 하늘 그라데이션 연장+비네팅, 캔버스 테두리 = 월드 경계(벽 색 외광) |
| 백버퍼 | 캔버스 = CSS 크기·devicePixelRatio. 벡터·파티클은 이 해상도로 그림 |
| 월드 기준/화면 기준 | 월드 기준(가로로 넓을 수 있음): 지형, 분화구·폭발 원(fireball/flash/ring), 네이팜 바닥, 벽, 구름. 화면 기준(정상 비율, 균일 배율 ks = ky·(kx/ky)^SPRITE_MIX): 탱크·방어막·낙하산, 투사체 몸체, 입자, 연기, 별, 선 굵기(지형 림·궤적·꼬리). 포신은 엔진 각도를 화면 각도로 변환해 탄 진행 방향과 일치 |
| 지형 | 엔진 마스크(1 game px 셀)를 kx×ky 로 확대. 셀 경계는 nearest, 윗면 림만 벡터 선(화면 균일 굵기, 아래 4) |
| 탱크 | SVG 1 game px = 4 unit, 배율 kt = max(ks×TANK_SCALE(2), TANK_MIN_CSS(2.2)×dpr) — 판정과 무관한 표시 배율, 번호 마커(4.5·kt, 14~40 CSS px)·턴 링·방어막·낙하산도 비례. 정상 비율. 표시 종횡비 때문에 가로는 판정 폭보다 좁고 세로는 조금 큼(SPRITE_MIX=0.5 절충, 1 이면 가로=판정 폭). 배율별·색별 오프스크린 캐시 |
| 마커·텍스트 | 화면 고정 크기(CSS px). 마커 18px, 숫자 최소 10px |
| 권장 | S=2 이상에서 탱크 7종 식별 확인됨(preview 3절). S=1은 마커로 구분 |

| PLAIN | 맑음 | #2F6FD0 → #6FB4F2 → #CDEBFF | 흰 구름 타원 alpha 0.22, 느린 수평 이동 2px/s |

| SUNSET | 노을 | #25184A → #9B3C6E → #F07C55 → #FFD08A | 지평선 근처 태양 방사 글로우 |

## 4. 지형
- 하늘마다 지형 색 세트(palette.json `skies.*.terrain`): `layers[0..2]` 깊이 그라데이션, `rim` 윗면 하이라이트, `rimDark` 림 아래 그림자, `speck` 점 질감.
- 층 표현: 표면과 평행한 지층선 4개, alpha 0.18.
- 윗면: rimDark 2.2 game px 위에 rim 1.1 game px. 지형이 파이면 림도 새 표면을 따라 다시 그림.
- 새로 생긴 흙(흙 무기): 0.15s 페이드 인.
- 그림자: 탱크 아래 타원(가로 11, 세로 1.4 game px, 검정 alpha 0.35).

## 5. 탱크
파일: `assets/tanks/tank_<type>_{hull,turret,barrel,wreck}.svg`, 메타: `tanks_meta.json`.

| type | 이름 | 실루엣 키 | 이동 |
|---|---|---|---|
| classic | 표준형 | 반구 돔 + 5바퀴 트레드 | 가능 |
| wedge | 쐐기형 | 낮은 육각 차체 + 납작 포탑 + 안테나 | 가능 |
| heavy | 중전차 | 사각 포탑·해치 + 측면 장갑판 + 굵은 포신(제퇴기) | 가능 |
| wheeled | 장륜형 | 큰 바퀴 3개, 트레드 없음 | 가능 |
| scout | 정찰형 | 기둥 위 구형 포탑(키 큼) | 가능 |
| fixed | 고정 포대 | 회색 콘크리트 받침 + 경고 띠, 바퀴 없음 | 불가(연료 구매 불가) |
| triple | 트리플 터렛 | 가장 큼, 포신 3개, 센서 렌즈 | 가능. 컴퓨터 전용, 미사일·베이비 미사일 3연발 |

- 성능 차이는 고정 포대(이동·연료 불가)와 트리플 터렛(컴퓨터 전용·3연발)뿐. 나머지 5종은 외형만 다름. 이름·한 줄 설명: tanks_meta.json `name_ko`, `desc_ko`, `can_move`, `cpu_only`.
- 원본 아이콘 수·모양과의 1:1 대응은 미확인(`verify`). 원본 아이콘을 볼 수 있으면 실루엣 키만 맞춰 조정한다.
- 레이어 순서: 그림자 → hull → barrel → turret → 방어막 → 마커.
- 앵커: viewBox(48×40)의 (24,40) = 엔진 탱크 위치(지면 접점).
- 포신: pivot(타입별, tanks_meta.json) 기준. 각도 0=오른쪽, 90=위, 180=왼쪽. 캔버스에서 `rotate(-angle)`.
- 삼연장은 그림 폭 11 game px로 다른 타입보다 크게 보이지만 판정 폭은 엔진 고정값.
- 재색칠: SVG의 토큰 `#FF00FF`(P), `#990099`(PD), `#FF99FF`(PL)을 플레이어 색으로 문자열 치환.
- 잔해: 색 고정(그을린 회갈색), 포탑 기울어짐, 포신 부러짐, 주황 균열. 사망 후 3s 연기(EFFECTS_SPEC).

|---|---|---|---|---|
| 1 | 빨강 | #FF3B3B | 원 | 흰 |
| 2 | 파랑 | #3D7BFF | 사각 | 흰 |
| 3 | 노랑 | #FFD21F | 삼각 | 검 |
| 4 | 초록 | #22C55E | 마름모 | 검 |
| 5 | 주황 | #FF8A1F | 오각 | 검 |

| 7 | 청록 | #1FD6F0 | 별 | 검 |
| 8 | 분홍 | #FF4FC3 | 십자 | 검 |
| 9 | 연두 | #C8F23A | 역삼각 | 검 |

- 음영: PD = base와 #0B0E16 48% 혼합, PL = base와 흰색 50% 혼합.
- 접근성: 색만으로 구분하지 않는다. 마커(형태+번호)는 항상 표시, 탱크 위 18px. 상단바·점수표·궤적 범례도 같은 마커를 쓴다.
- 색약 위험쌍(초록/연두/노랑, 빨강/주황, 파랑/보라)은 마커 형태가 서로 다르다.
- 궤적(Trace Paths)·트레이서는 자기 색. 겹칠 때 구분은 마커로.

## 7. 상태 표시
| 상태 | 표시 |
|---|---|
| 현재 턴 | 발밑 링(fx_turn_ring, 자기 색 + 흰 점선) + 마커 위 꺾쇠(0.8s 주기 2px 바운스) |
| 동시 모드 준비 | 마커 오른쪽 위 초록 체크 |
| 방어막 | fx_shield_*, alpha = 0.35 + 0.65·남은 비율, 25% 미만 6Hz 깜빡임 |
| 낙하산 | (별도 에셋 미작성) |

방어막 4종: 방어막=하늘색 거품+하이라이트, 역장=민트 육각 격자+바깥 꺾쇠 4개, 중장갑=호박색 두꺼운 이중 링+판 이음매 8개, 초자력=보라 자기장 궤도 3개+점선 외곽.

## 8. 벽
원본 색 의미 유지. 좌우 끝 2 game px 막대 + 같은 색 외광(6px, alpha 0.35).
NONE #8A8F98 · CONCRETE #FFFFFF · PADDED #3BD16F · RUBBER #FF4040 · SPRING #22D3EE · WRAP #FFD21F. ERRATIC은 샷마다 0.2s 색 전환.

## 9. 성능
- 탱크 이미지: (타입×색×배율) 오프스크린 캐시. 매 프레임 SVG 디코드 금지.
- 파티클 상한 1500. 저사양 옵션: 파티클 ×0.4, 흔들림·열 왜곡·연기 기둥 끔.
- 화면 흔들림·섬광은 `prefers-reduced-motion`이면 끄거나 약하게.

## 10. 캔버스 밖 UI (모든 화면 공통)
- 기준: 회색 베벨 레트로 스킨. 토큰은 `public/css/retro.css`의 `--se-*`(면 `--se-face`, 볼록 `--se-raised`, 오목 `--se-sunken`, 창 `--se-frame`). `app.css`의 다크 값은 바탕 레이아웃용이며 화면에 그대로 보이면 안 된다.
- 글꼴: 본문 `--se-font`, 숫자(돈·시간·수량) `--se-mono`. 모서리 0, 전환 애니메이션 없음.
- 버튼·탭·칩 = 볼록, 누름·선택 = 오목 + 밝은 면. 기본 버튼 = 검정 2px 링 + ▶. 입력·목록 행·카드 = 오목. 창 제목·구획 = 홈 구분선(3C 위 DE). 색 버튼은 발사(빨강)뿐.
- 적용 범위: 닉네임·로비·대기실, 게임 HUD·조작·플레이어·채팅, 상점, 모든 레이어(모달·시트·드로어), 결과, 토스트, 부팅 화면. 새 UI는 해당 범위 선택자에 넣어 같은 규칙을 받게 한다.
- 오류·거절은 토스트로만. 설명 문구는 한 줄 이내.
- 게임 HUD: 바람과 시간은 같은 2줄 칸(윗줄 숫자 18px `--se-mono`, 아랫줄 오목 막대 8px). 바람 = 방향 화살표 + 세기, 막대는 가운데 눈금에서 부는 쪽으로 참(`--se-cpu`). 버튼 묶음(`.hud-btns`)은 좁은 화면 = 상단 바 오른쪽 끝(홈 구분선), wide = 좌 패널 첫 줄 오른쪽 끝.

## 11. 미리보기·재생성
