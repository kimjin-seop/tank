
## 0.4 한국어 현지화 원칙 (사용자 확정, 갱신)
- **이름은 음역·원어 중심, 설명은 의역**이다. 창작식 의역으로 이름을 바꾸지 않는다.
  - 일반 한국어로 이미 통하는 말(미사일, 네이팜, 레이저, 핵폭탄, 배터리, 파라슈트 등)은 그대로 쓴다.
  - 고유명·음역이 자연스러운 이름(헬파이어, 펑키 봄브, 레이지 보이 등)은 음역하고, 약어·고유 표기(MIRV)는 원어 그대로 쓴다.
  - 설명문, 메뉴 문구, 시스템 메시지, 안내, AI 대사만 자연스러운 한국어로 의역한다.
- 용어는 8절 용어집이 단일 기준이다. 표에 없는 문구가 필요하면 임의로 만들지 말고 기획에 추가를 요청한다.
- 키 입력 단축키는 원본 알파벳 키를 그대로 쓰고 키 안내 라벨만 한글로 표시한다(예: "발사 [Space]"). 유도 시스템 약칭(Ht, B, H, V, L)은 원본 알파벳 그대로 쓴다.

### 8.9 용어집 운영 규칙
- 번역 문구는 이 표 한 곳에서만 정의하고, 코드에서는 키(원문 영문 ID)로 참조한다 [제안: i18n 리소스 파일 1개].
- 데이터(무기 ID 등)는 영문 원본 ID를 유지하고, 화면 표기만 한국어로 바꾼다. 서버 규칙·수치는 이 번역과 무관하다.
- 한국어로 바꾼 뒤에도 원본의 글자 수 제한(상단바 폭 등)이 문제될 수 있다. 게임 화면 안의 상단바 텍스트를 원본 톤으로 둘지 HUD로 현대화할지는 A11과 함께 사용자가 정한다.
- 추가·변경 이력은 이 표를 수정하는 것으로 관리한다.
